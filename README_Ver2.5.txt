古堅南FC 公式ホームページ Ver.2.5
「選手登録・写真かんたん更新版」

追加機能
・player-admin.html を新規追加
・選手の追加 / 編集 / 削除
・カテゴリー / 背番号 / 学年 / ポジション / 利き足
・ニックネーム / 身長 / 好きな選手 / 得意なプレー / 目標 / 紹介文
・写真選択プレビュー
・写真の推奨ファイル名を自動表示
・更新後の players.json をワンタップで書き出し
・ブラウザ内の編集内容は localStorage に一時保存
・選手一覧 / 個人プロフィールは既存Ver.2.4機能を継承

重要
GitHub Pagesは静的サイトのため、管理画面からGitHubへ直接保存はできません。
Ver.2.5の更新手順：
1. player-admin.html を開く
2. 選手データを入力・保存
3. players.json を書き出す
4. GitHubフォルダの data/players.json と置き換える
5. 写真を images/players/ に入れる
6. GitHub Desktopで Commit → Push
