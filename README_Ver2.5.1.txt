古堅南FC 公式ホームページ Ver.2.5.1
「選手写真・保存改善版」

Ver.2.5からの改善
・写真を選択後、「この選手を保存」を押しても写真プレビューが消えないよう修正
・選択写真をブラウザ内 localStorage に保持
・選手を開き直した時も保存済みの写真プレビューを復元
・「写真を書き出す」ボタンを追加
・写真を推奨ファイル名でMacへ保存可能
・「選択写真を外す」ボタンを追加
・players.json の photo パスと写真ファイル名を自動一致
・誤って players.json を先に書き出しても公開サイトは自動変更されない安全設計

推奨更新手順
1. player-admin.html を開く
2. 選手を選ぶ / 新しい選手を追加
3. 写真を選ぶ
4. 「この選手を保存」
5. 「写真を書き出す」
6. 「players.jsonを書き出す」
7. ダウンロードした写真を GitHubフォルダの images/players/ へ入れる
8. players.json を data/players.json に上書き
9. GitHub Desktopで Commit → Push
