古堅南FC 公式ホームページ Ver.1.6.3
======================================

■ Ver.1.6.3「選手紹介 公開画面整理版」

選手紹介ページを、一般公開用として見やすく整理しました。

■ 変更点
- 公開ページから「選手登録方法」を削除
- 公開ページから「実選手データ登録」案内を削除
- 閲覧者には選手プロフィールだけが表示される構成へ変更
- U-12 / U-11 / U-10 タブ切替は維持
- 氏名 / 学年 / 背番号 / ポジション / 利き足 / 写真 / 紹介文の表示機能は維持
- JSONによる選手データ管理機能は維持
- PC / iPhone対応

■ 管理方法
選手データの更新は引き続き
data/players.json
で行います。

写真は
images/players/
に追加します。

■ GitHub
「更新用ファイルのみ」ZIPを展開してアップロードしてください。
