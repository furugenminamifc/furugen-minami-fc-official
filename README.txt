古堅南FC 公式ホームページ Ver.1.7.4
======================================

■ Ver.1.7.4「実選手複数名かんたん登録版」

実際の選手を1名ずつ追加しながら、
複数名をまとめて players.json に保存できる専用ページを追加しました。

■ 新規ページ
multi-player-manager.html

■ できること
- U-12 / U-11 / U-10
- 背番号
- 氏名
- ふりがな
- 学年
- ポジション
- 利き足
- CAPTAIN
- 公開 / 非公開
- ひとこと紹介
- 写真選択
- 写真プレビュー
- 写真ファイル名自動入力
- 写真位置
- 複数選手を登録リストへ追加
- 登録人数カウント
- 選手情報の編集
- 選手削除
- 選手カード簡易プレビュー
- players.json 保存
- JSONコピー

■ 実運用
1. multi-player-manager.html を開く
2. 1人目を入力して「登録リストへ追加」
3. 「次の選手を入力」
4. 2人目、3人目…と繰り返す
5. 全員入力後 players.json を保存
6. 選手写真を GitHub の images/players/ にまとめてアップロード
7. players.json を data/players.json と入れ替える
8. Commit changes
9. 選手紹介ページで確認

■ 注意
写真選択はブラウザ内プレビュー用です。
写真そのもののGitHubアップロードは手動です。

■ 公開ページ
players.html は一般公開用です。
