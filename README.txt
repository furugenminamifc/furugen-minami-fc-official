古堅南FC 公式ホームページ Ver.1.7.3
======================================

■ Ver.1.7.3「実選手1名登録・写真表示確認版」

実際の選手をまず1名だけ登録し、
写真・氏名・背番号・カテゴリー・学年・ポジションが
正しく表示できるか確認するための専用機能を追加しました。

■ 新規ページ
one-player-check.html

■ できること
- U-12 / U-11 / U-10
- 背番号
- 氏名
- ふりがな
- 学年
- ポジション
- 利き足
- 写真選択
- 写真プレビュー
- 写真ファイル名自動入力
- 紹介文
- 1名専用 players.json 作成
- players.json 保存

■ 実運用の流れ
1. one-player-check.html を開く
2. 実際の選手1名を入力
3. 写真を選択してプレビュー確認
4. players.json を保存
5. 選手写真を GitHub の images/players/ へアップロード
6. players.json を GitHub の data/players.json と入れ替える
7. Commit changes
8. 選手紹介ページで写真表示を確認

■ 重要
写真の選択はブラウザ内プレビューです。
写真そのもののGitHubアップロードは手動で行います。

■ 公開ページ
players.html は一般公開用です。
