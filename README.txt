古堅南FC 公式ホームページ Ver.1.6.7
======================================

■ Ver.1.6.7「実選手登録・写真表示仕上げ版」

実際の選手写真を登録した時に、公式ホームページとして
きれいに表示できるよう写真表示を仕上げました。

■ 改善内容
- 選手写真を4:5比率で統一
- 写真位置 photoPosition に対応
- 写真表示方式 photoFit に対応
- 写真キャッシュ対策
- 写真読み込み失敗時のPHOTO表示
- 写真なしの場合も背番号入り仮カード表示
- 1名 / 2名 / 3名 / 4名以上の自動中央配置
- 背番号順自動整列
- CAPTAIN表示
- PC / タブレット / iPhone対応

■ 推奨写真
比率：4:5
目安：1200 x 1500px前後
形式：WebP / JPG / PNG

■ 写真位置調整
例：
"photoPosition": "center 35%"

顔を少し上に見せたい場合：
"photoPosition": "center 25%"

■ 選手データ管理
data/players.json

■ 写真保存先
images/players/

■ 補助ツール
player-manager.html からJSONを作成できます。

■ GitHub
「更新用ファイルのみ」ZIPを展開してアップロードしてください。
