古堅南FC 公式ホームページ Ver.1.6
====================================

■ Ver.1.6「選手紹介 実用化版」

U-12 / U-11 / U-10 の選手紹介を、
JSONデータから実運用できるようにしました。

■ 登録できる項目
- カテゴリー
- 背番号
- 氏名
- ポジション
- 写真
- 写真位置
- ひとことメッセージ
- 公開 / 非公開

■ 写真
images/players/ に画像を追加します。

■ 選手データ
data/players.json を編集します。

■ 例
{
  "category": "U-12",
  "number": 10,
  "name": "氏名",
  "position": "MF / FW",
  "photo": "images/players/u12-02.webp",
  "photoPosition": "center 35%",
  "message": "ひとことメッセージ",
  "isPublished": true
}

■ 表示
- U-12 / U-11 / U-10 をタブ切替
- 写真なしの場合は背番号入り仮カード
- スマホ対応
- 年度情報対応
- 画像は後から追加可能

■ 個人情報
誕生日・住所・連絡先などの個人情報は初期状態では公開しません。

■ GitHub
「更新用ファイルのみ」ZIPを展開してアップロードしてください。
