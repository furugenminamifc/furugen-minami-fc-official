古堅南FC 公式ホームページ Ver.1.6.9

■ Ver.1.6.9「選手カード写真表示・デザイン仕上げ版」

選手カードの写真表示と、写真未登録時の見た目を整理しました。

■ 改善内容
- 写真未登録時の「PHOTO」文字を削除
- 写真未登録時は背番号だけを中央に大きく表示
- 写真登録時は写真を主役に表示
- 写真上の背番号表示を維持
- 写真読み込み失敗時も背番号で代替表示
- 氏名 / 学年 / ポジション / 利き足 / 紹介文を整理
- 1名 / 2名 / 3名 / 4名以上の自動中央配置を維持
- CAPTAIN表示を維持
- PC / タブレット / iPhone対応
