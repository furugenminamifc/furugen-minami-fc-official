古堅南FC 公式ホームページ Ver.1.7.2
======================================

■ Ver.1.7.2「実選手かんたん登録・写真アップロード版」

テスト選手表示を終了し、実際の選手登録へ進める版です。

■ 主な改善
- player-manager.html を実選手登録専用画面へ改善
- 氏名未入力時のチェック
- 背番号未入力時のチェック
- ローカル写真選択
- 選択した写真のプレビュー
- 写真ファイル名の自動入力
- U-12 / U-11 / U-10
- 学年
- ポジション
- 利き足
- CAPTAIN
- 公開 / 非公開
- ひとこと紹介
- 登録済み選手一覧
- 選手カード簡易プレビュー
- players.json 保存
- JSONコピー

■ 実際の運用
1. player-manager.html を開く
2. 選手写真を選ぶ
3. 氏名・背番号などを入力
4. 「登録リストへ追加」
5. 全員登録
6. players.json を保存
7. 選んだ写真を GitHub の images/players/ へアップロード
8. players.json を GitHub の data/players.json と入れ替える
9. Commit changes

■ 重要
写真選択はブラウザ内でのプレビュー確認です。
GitHubへの写真アップロード自体は、これまで通りGitHub画面から行います。

■ 公開ページ
players.html は一般公開用です。
