古堅南FC 公式ホームページ Ver.1.5.1
======================================

■ Ver.1.5.1「スタッフ紹介 実用化版」

スタッフページを実データ運用できるように改良しました。

■ 主な更新
- data/staff.json を追加
- 代表・監督 / コーチ / スタッフをJSONで管理
- 氏名 / 役職 / 担当カテゴリー / 資格 / メッセージを登録可能
- 写真を後から追加可能
- 画像は images/staff/ フォルダに保存
- js/staff.js が自動でスタッフカードを生成
- PC / iPhone対応
- Ver.1.5のその他ページは維持

■ 写真追加例
images/staff/coach-gima.webp

staff.json の photo に
"images/staff/coach-gima.webp"
と入力すると表示されます。

■ GitHub更新
「更新用ファイルのみ」ZIPを展開して中身をアップロードしてください。
