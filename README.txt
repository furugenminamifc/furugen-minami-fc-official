古堅南FC 公式ホームページ Ver.1.7.1
======================================

■ Ver.1.7.1「実選手登録・写真表示テスト版」

実際の運用前に、1名分のテスト選手データとテスト画像を登録して、
選手プロフィール表示が正しく動作するか確認できる版です。

■ テスト表示内容
- カテゴリー：U-12
- 背番号：8
- 氏名：テスト選手
- 学年：6年生
- ポジション：MF / FW
- 利き足：右
- テスト画像表示
- 紹介文表示

■ テスト画像
images/players/test-player-01.svg

実際の選手写真へ切り替える時は、
data/players.json の photo を
images/players/実際のファイル名
へ変更してください。

■ 確認ポイント
1. U-12を開く
2. テスト選手カードが中央に表示される
3. 背番号8が表示される
4. テスト画像が表示される
5. 氏名・学年・ポジション・利き足が表示される

更新用ZIPを展開してアップロードしてください。
