古堅南FC 公式ホームページ Ver.1.5.5
======================================

■ Ver.1.5.5「保護者会運営表記 改善版」

スタッフページの「運営スタッフ」個人カードを廃止し、
運営を「古堅南FC 保護者会」全体として表示する構成に変更しました。

■ スタッフページ構成
- 指導スタッフ
  - 代表・監督
  - コーチ
- 審判員
- 運営
  - 古堅南FC 保護者会
  - チーム運営は保護者会全員で協力して行っています。

■ 主な改善
- 運営スタッフ個人名の掲載をやめ、保護者会全体として表記
- 保護者会の運営内容を箇条書きで表示
- 指導スタッフ・審判員プロフィール機能は維持
- PC / iPhone対応
- 画像変更なし、プログラムデータのみ更新

■ GitHub
「更新用ファイルのみ」ZIPを展開してアップロードしてください。
