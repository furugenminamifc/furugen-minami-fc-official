古堅南FC 公式ホームページ Ver.1.6.5

■ Ver.1.6.5「選手カード自動レイアウト・中央配置版」

選手人数に応じて、カード配置が自動調整されるように改善しました。

■ 自動配置
- 1名：中央に1枚
- 2名：中央に2枚
- 3名：中央に3枚
- 4名以上：画面幅に応じて自動折り返し
- PC / タブレット / iPhone 対応

■ 維持している機能
- U-12 / U-11 / U-10 タブ切替
- 写真
- 背番号
- 氏名
- ふりがな
- 学年
- ポジション
- 利き足
- プロフィール
- CAPTAIN表示
- 背番号順自動整列
- JSONデータ管理
