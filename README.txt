古堅南FC 公式ホームページ Ver.1.6.6
======================================

■ Ver.1.6.6「選手データ登録・更新簡単化版」

選手データ更新を簡単にする補助ツールを追加しました。

■ 新規
player-manager.html

このページをMac上で開くと、
フォーム入力だけで選手データJSONを作成できます。

■ できること
- U-12 / U-11 / U-10 選択
- 背番号
- 氏名
- ふりがな
- 学年
- ポジション
- 利き足
- 紹介文
- 写真パス
- CAPTAIN
- 公開 / 非公開
- 選手削除
- 完成JSONコピー
- players.json 保存

■ 公開サイト
player-manager.html は管理補助用です。
一般公開の選手紹介画面 players.html は従来どおりシンプルな公開ページです。

■ GitHub
更新用ZIPを展開してアップロードしてください。
