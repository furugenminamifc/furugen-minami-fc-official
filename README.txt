古堅南FC 公式ホームページ Ver.1.0
====================================

■ 方針
既存の古堅南FCアプリとは完全分離した、軽量な静的ホームページです。
データベース・Supabase・AI Coachには接続していません。

■ 構成
index.html        トップページ
category.html     U-12 / U-11 / U-10 の年度別紹介ページ
css/style.css     デザイン
js/category.js    カテゴリーデータを表示する最小限のJavaScript
data/2026/        年度別データ
images/           今後、本物の写真を入れる場所

■ 毎年の更新方法
1. data/2026/ をコピーして data/2027/ を作る
2. u-12.json / u-11.json / u-10.json の内容を2027年度用に変更
3. category.html の年度選択に「2027年度」を追加
4. 新しい写真を images/ に追加
5. GitHub Pagesへアップロード

■ 写真について
現在は軽量なCSSビジュアルを使用しています。
実際の古堅南FC写真を受け取ったら、画像をWeb用に圧縮して差し替える想定です。

■ GitHub Pages
このフォルダを新しいGitHubリポジトリにアップロードし、GitHub Pagesを有効にします。
既存の古堅南FCアプリのリポジトリにはアップロードしないでください。
