古堅南FC 公式ホームページ Ver.1.6.2
======================================

■ Ver.1.6.2「実選手データ登録版」

Ver.1.6.1の選手プロフィール機能を維持しつつ、
実際の選手データを登録しやすい形に整理しました。

■ 実選手登録の流れ
1. 選手写真を images/players/ に追加
2. data/players.json に選手情報を追加
3. category を U-12 / U-11 / U-10 から指定
4. isPublished を true にして公開

■ 登録項目
- 氏名
- ふりがな
- 学年
- 背番号
- ポジション
- 利き足
- プロフィール
- 写真
- 写真位置
- 公開 / 非公開

■ 登録例
data/player-actual-template.json をコピーして使用できます。

■ 個人情報
誕生日・住所・電話番号・学校名など、必要以上の個人情報は公開しない設計です。
公開内容はチームで許可を得た項目だけ使用してください。

■ GitHub
「更新用ファイルのみ」ZIPを展開してアップロードしてください。
