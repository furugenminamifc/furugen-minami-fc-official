古堅南FC 公式ホームページ Ver.2.3「選手紹介・カテゴリー完成版」

Ver.2.2をベースに、選手紹介とカテゴリー導線を大幅改善しました。

主な改善
・選手紹介ページを U-12 / U-11 / U-10 の切替式に変更
・カテゴリーごとに選手人数、学年、紹介文を表示
・選手カードを「写真・背番号・名前・ふりがな・学年・ポジション・利き足」で統一
・写真未登録時は壊れた画像を出さず、サッカーボール付きプレースホルダーを表示
・カテゴリー年度ページを完成形へ改良
・U-12 / U-11 / U-10 の年度ページから選手紹介・試合予定・試合結果へ移動可能
・data/players.json を更新するだけで選手カードへ自動反映
・PC / iPhone / Android / タブレット対応
・Ver.2.2のチーム写真・エンブレム表示改善を継承
・既存Git管理情報（.git）は含めていません
