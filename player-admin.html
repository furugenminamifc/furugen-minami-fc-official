ADMIN / PLAYER UPDATE

選手登録・写真かんたん更新

名前・カテゴリー・背番号・学年・ポジション・利き足・プロフィールを、画面から入力できます。写真も選ぶだけでプレビューできます。最後に「更新データを書き出す」で、GitHubへ入れ替えるファイルを作成します。

⚽PLAYER PHOTO
写真を選ぶと、この画面でプレビューできます。
「この選手を保存」を押しても写真プレビューは消えません。
公開用には「写真を書き出す」で推奨ファイル名の写真を保存し、GitHubの images/players/ へ入れます。
写真はまだ選択されていません。

更新データを書き出す

編集が終わったら、下のボタンで新しい players.json を作成できます。ダウンロードしたファイルをホームページの data フォルダへ上書きすれば、選手一覧とプロフィールへ反映されます。

重要： GitHub Pagesは静的ホームページなので、この管理画面からGitHubへ直接保存はできません。
Ver.2.5.1では「入力 → players.jsonを書き出す → GitHubフォルダへ上書き」の3段階に簡単化しています。
